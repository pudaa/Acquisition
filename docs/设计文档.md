# 致知（Acquisition）虚拟仿真实验平台设计文档

## 一、定位

虚拟实验平台

## 二、技术栈

- 前端：Vue3
- 后端：node.js + Express

## 三、项目介绍

本项目主要围绕虚拟仿真实验的实现展开，帮助学生通过自主学习掌握实验相关知识和注意事项等内容。

### 3.1 模块设计

项目分为教师端和学生端，用户在登录后根据用户等级判断进入的端口类型。教师端和学生端均有 AI 助教辅助，优化教学效果。

#### 3.1.1 教师端

教师端主要负责学生实验数据收集分析、实验内容上传与管理。登录后侧边栏将显示五个视图导航按钮：学生管理视图、实验查看视图、实验上传视图、讨论区视图和班级管理视图。

##### 3.1.1.1 学生成绩视图

教师可查看所有学生信息（支持搜索检索），学生信息以列表形式展示，点击列表项可展开详细信息。展开面板包含学生当前所有学习任务及对应实验的完成进度和练习成绩，支持通过 "添加实验任务" 按钮为学生布置任务。

##### 3.1.1.2 实验查看视图

学生完成实验学习/测试后，其学习进度与操作数据（主要为实验目标节点完成情况）会上传至数据库。
实验查看界面通过图表呈现数据：未选择特定实验时，展示 "实验完成率分布"、 "学习进度详情" 、"难度分布"；选择特定实验后，显示该实验下学生完成情况（学生完成率以倒序水平柱状图展示，目标完成率以饼图展示各节点完成次数）。通过数据可视化分析，教师可精准定位学生薄弱环节。

##### 3.1.1.3 实验上传视图

教师可以在这个视图中上传文件，丰富实验内容。

##### 3.1.1.4 讨论区视图

教师可发布讨论话题，学生可参与话题讨论。教师可以置顶或删除学生的话题。

##### 3.1.1.5 班级管理视图

在班级管理视图中，教师对本班学生进行管理，包括添加、删除学生和修改班级名称。

#### 3.1.2 学生端

学生登录后进入导航窗口（含导航栏与内容窗口），通过导航栏切换以下四个学习视图：实验列表视图、实验列表视图、讨论区视图和错题本视图。

##### 3.1.2.1 实验列表视图

展示数据库所有实验（支持检索），未学习实验显示 "添加至我的任务" 按钮，点击后实验加入个人任务视图，支持个性化学习。

##### 3.1.2.2 实验任务视图

展示教师发布/自主添加的实验：初次添加实验归入 "未完成" 栏（显示最大进度），完成后移入 "已完成" 栏。所有实验（无论完成状态）均可点击进入学习。

##### 3.1.2.3 讨论区视图

学生可创建/回复讨论话题（支持文字、图片等形式），与教师互动交流。

##### 3.1.2.4 错题本视图

学生在错题本视图中可以查看自己在实验练习中的易错题目以及正确答案

### 3.2 实验学习设计

实验学习包含视图文件与实验文件两部分。
学生进入学习时，平台根据所选实验加载实验文件并生成学习目标。实验过程中完成目标时，右侧学习目标栏同步更新（操作数据上传至数据库）。目标设有权重，完成后按权重计算学习进度。学生在实验学习时可以根据提供的电子元件搭建电路以完成实验目标，实验目标通过结构法和行为法两种途径检测，为学生的电路搭建提供较大的自由空间，学生可以利用所学知识来进行搭建。当全部目标完成时，界面会弹出提示框，学生可选择离开、继续学习或下载实验报告（含学生信息、目标完成情况、学生电路查看，支持 PDF 格式下载）。

学生在实验中可以进行答题，题库中存储的题目分为高中低三种难度，根据学生的答题情况，后端判断学生的掌握程度，从而实时更新不同难度的出现频率，同时不同难度的题目在掌握程度的计算有着不同的权重，方便精确定位学生的掌握程度。

实验设计由简入难，包含“了解电路”、“与门搭建实验”、“或门搭建实验”、“非门搭建实验”、“与非门基本触发器搭建实验”和“多谐振荡器搭建实验”多个电路实验。学生可以在学习中逐渐加深对电路的理解。

### 3.3 AI 助手

AI 助手基于扣子平台智能体实现：完成训练并发布智能体后，通过获取的智能体 ID 与 API 令牌调用接口。学生学习过程中点击 "AI 助手" 按钮即可与智能体交互，辅助实验学习。

## 四、数据表设计

```sql

-- 用户表

CREATE TABLE `users` (
    `id` int NOT NULL AUTO_INCREMENT,
    `username` varchar(50) COLLATE utf8mb4_bin NOT NULL COMMENT '学生学号',
    `password` varchar(255) COLLATE utf8mb4_bin NOT NULL,
    `created_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    `role` varchar(20) COLLATE utf8mb4_bin NOT NULL DEFAULT 'student',
    `avatar_url` varchar(255) COLLATE utf8mb4_bin DEFAULT '/default_avatar.png' COMMENT '头像存储路径',
    `realname` varchar(255) COLLATE utf8mb4_bin DEFAULT NULL COMMENT '学生姓名',
    `class_name` varchar(255) COLLATE utf8mb4_bin DEFAULT 'default_class' COMMENT '班级字段，用于存储班级信息',
    PRIMARY KEY (`id`),
    UNIQUE KEY `username` (`username`),
    UNIQUE KEY `email_UNIQUE` (`realname`)
) ENGINE = InnoDB AUTO_INCREMENT = 12 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin


-- 实验主表

CREATE TABLE `experiments` (
    `exp_id` int NOT NULL AUTO_INCREMENT,
    `title` varchar(100) COLLATE utf8mb4_bin NOT NULL,
    `subject` varchar(50) COLLATE utf8mb4_bin NOT NULL,
    `difficulty` enum(
        'basic',
        'intermediate',
        'advanced'
    ) COLLATE utf8mb4_bin NOT NULL,
    `cover_url` varchar(200) COLLATE utf8mb4_bin DEFAULT NULL,
    `duration` smallint NOT NULL,
    `steps` json NOT NULL,
    `introduce` varchar(255) COLLATE utf8mb4_bin DEFAULT NULL COMMENT '实验介绍',
    `guidance` varchar(500) COLLATE utf8mb4_bin DEFAULT NULL COMMENT '操作指导',
    `prepare` varchar(255) COLLATE utf8mb4_bin DEFAULT NULL COMMENT '实验准备',
    `element` json DEFAULT NULL,
    PRIMARY KEY (`exp_id`)
) ENGINE = InnoDB AUTO_INCREMENT = 7 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin


-- 用户-实验关联表（跟踪学习进度）

CREATE TABLE `user_experiments` (
    `ue_id` int NOT NULL AUTO_INCREMENT,
    `user_id` int NOT NULL,
    `exp_id` int NOT NULL,
    `progress` float DEFAULT '0',
    `is_completed` tinyint(1) DEFAULT '0',
    `last_studied` datetime DEFAULT NULL,
    PRIMARY KEY (`ue_id`),
    UNIQUE KEY `user_id` (`user_id`, `exp_id`)
) ENGINE = InnoDB AUTO_INCREMENT = 3 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin


-- 用户操作进度表

CREATE TABLE `experiment_attempts` (
    `attempt_id` int NOT NULL AUTO_INCREMENT,
    `user_id` int NOT NULL,
    `exp_id` int NOT NULL,
    `start_time` datetime DEFAULT CURRENT_TIMESTAMP,
    `end_time` datetime DEFAULT NULL,
    `progress` float DEFAULT '0',
    `is_completed` tinyint(1) DEFAULT '0',
    `operations` json DEFAULT NULL,
    `goals` json DEFAULT NULL,
    PRIMARY KEY (`attempt_id`),
    KEY `user_id` (`user_id`),
    KEY `exp_id` (`exp_id`),
    CONSTRAINT `experiment_attempts_ibfk_1` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`),
    CONSTRAINT `experiment_attempts_ibfk_2` FOREIGN KEY (`exp_id`) REFERENCES `experiments` (`exp_id`)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin


-- 讨论话题表

CREATE TABLE `discussion_topics` (
    `id` int NOT NULL AUTO_INCREMENT,
    `title` varchar(255) COLLATE utf8mb4_bin NOT NULL,
    `content` text COLLATE utf8mb4_bin NOT NULL,
    `author_id` int NOT NULL,
    `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
    `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    `is_pinned` tinyint(1) DEFAULT '0',
    `class_name` varchar(255) COLLATE utf8mb4_bin DEFAULT NULL COMMENT '讨论区分类',
    PRIMARY KEY (`id`),
    KEY `author_id` (`author_id`),
    CONSTRAINT `discussion_topics_ibfk_1` FOREIGN KEY (`author_id`) REFERENCES `users` (`id`)
) ENGINE = InnoDB AUTO_INCREMENT = 12 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin


-- 讨论回复表

CREATE TABLE `discussion_replies` (
    `id` int NOT NULL AUTO_INCREMENT,
    `topic_id` int NOT NULL,
    `content` text COLLATE utf8mb4_bin NOT NULL,
    `author_id` int NOT NULL,
    `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    KEY `topic_id` (`topic_id`),
    KEY `author_id` (`author_id`),
    CONSTRAINT `discussion_replies_ibfk_1` FOREIGN KEY (`topic_id`) REFERENCES `discussion_topics` (`id`) ON DELETE CASCADE,
    CONSTRAINT `discussion_replies_ibfk_2` FOREIGN KEY (`author_id`) REFERENCES `users` (`id`)
) ENGINE = InnoDB AUTO_INCREMENT = 10 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin


-- 测试题库表

CREATE TABLE `questions` (
    `id` int NOT NULL AUTO_INCREMENT,
    `exp_id` int NOT NULL,
    `title` text COLLATE utf8mb4_bin NOT NULL,
    `type` enum('single', 'multiple') COLLATE utf8mb4_bin NOT NULL,
    `difficulty` enum('high', 'medium', 'low') COLLATE utf8mb4_bin NOT NULL,
    `weight` int NOT NULL,
    `options` json NOT NULL,
    `correct_answers` json NOT NULL,
    `knowledge_point` varchar(255) COLLATE utf8mb4_bin DEFAULT NULL,
    PRIMARY KEY (`id`),
    KEY `exp_id` (`exp_id`),
    CONSTRAINT `questions_ibfk_1` FOREIGN KEY (`exp_id`) REFERENCES `experiments` (`exp_id`)
) ENGINE = InnoDB AUTO_INCREMENT = 100 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin

-- 用户掌握程度以及总分表

CREATE TABLE `practice_sessions` (
    `id` int NOT NULL AUTO_INCREMENT,
    `user_id` int NOT NULL,
    `exp_id` int NOT NULL,
    `total_score` int NOT NULL,
    `mastery_score` float NOT NULL,
    `completed_at` datetime DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    KEY `user_id` (`user_id`),
    KEY `exp_id` (`exp_id`),
    CONSTRAINT `practice_sessions_ibfk_1` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`),
    CONSTRAINT `practice_sessions_ibfk_2` FOREIGN KEY (`exp_id`) REFERENCES `experiments` (`exp_id`)
) ENGINE = InnoDB AUTO_INCREMENT = 21 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin

-- 用户答题记录表

CREATE TABLE `practice_records` (
    `id` int NOT NULL AUTO_INCREMENT,
    `user_id` int NOT NULL,
    `exp_id` int NOT NULL,
    `question_id` int NOT NULL,
    `user_answer` json NOT NULL,
    `is_correct` tinyint(1) NOT NULL,
    `difficulty` enum('high', 'medium', 'low') COLLATE utf8mb4_bin NOT NULL,
    `score` int NOT NULL,
    `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    KEY `user_id` (`user_id`),
    KEY `exp_id` (`exp_id`),
    KEY `question_id` (`question_id`),
    CONSTRAINT `practice_records_ibfk_1` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`),
    CONSTRAINT `practice_records_ibfk_2` FOREIGN KEY (`exp_id`) REFERENCES `experiments` (`exp_id`),
    CONSTRAINT `practice_records_ibfk_3` FOREIGN KEY (`question_id`) REFERENCES `questions` (`id`)
) ENGINE = InnoDB AUTO_INCREMENT = 151 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin

-- 电子元件编号及介绍表

CREATE TABLE `elements` (
    `id` int NOT NULL AUTO_INCREMENT COMMENT 'Primary Key',
    `create_time` datetime DEFAULT NULL COMMENT 'Create Time',
    `name` varchar(255) COLLATE utf8mb4_bin DEFAULT NULL,
    `introduction` text COLLATE utf8mb4_bin COMMENT '元件简介',
    PRIMARY KEY (`id`)
) ENGINE = InnoDB AUTO_INCREMENT = 15 DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_bin
```
