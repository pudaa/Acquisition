## 二、架构总览

### 引擎模块依赖关系

```
ExperimentEngine.vue
  ├─ simulation-engine.js  ──→  time-manager.js
  │                           └─→  circuit-core.js ──→ circuit-component.js
  │                           └─→  goal-system.js ──→ workflow-engine.js
  ├─ circuit-draw.js ──→ renderer-registry.js (注册式绘制)
  ├─ circuit-component.js (引脚系统)
  └─ component-registry.js (ID 管理)
```

### 数据流

```
用户操作 (点击/拖放)
  → components[] 修改 (含 ComponentRegistry 分配 ID)
  → SimulationEngine._loop() 下一帧
     → TimeManager.tick() → dt
     → solveCircuit(components, GRID_SIZE, state, dt)
        → Newton-Raphson 迭代 (非线性收敛)
        → 更新 comp.lit, state.lastV
     → GoalEngine.checkAll() (detector / workflow)
     → onRender({ components, voltages, goals, progress })
        → draw() → engineDrawGrid + drawComponent + drawWire
        → emit('progress-update') → 父组件更新 GoalPanel
```

### 后端 API

| 接口 | 方法 | 用途 |
|---|---|---|
| `/api/experiments/:id/config` | GET | 返回实验配置 (`engineMode`, `config`) |
| `/api/experiments/:id/steps` | GET | 返回学习步骤 (用于右侧 GoalPanel) |
| `/api/experiments/:id/title` | GET | 返回实验标题 |
| `/api/experiments/save-progress` | POST | 保存学习进度 |

## 三、工作流检测系统

### 用法

在配置的 `goals[]` 中使用 `type: "workflow"`:

```json
{
  "id": "GOAL_BULB_LIT",
  "title": "让灯泡发光",
  "type": "workflow",
  "weight": 2,
  "workflow": [
    { "action": "find_component", "type": "bulb", "store": "bulb" },
    { "action": "read_property", "source": "$bulb", "property": "lit", "store": "isLit" },
    { "action": "assert", "source": "$isLit", "title": "灯泡已发光" }
  ]
}
```

### 内置步骤

| 步骤 | 功能 | 关键参数 |
|---|---|---|
| `find_component` | 按 type/id 查找 | `type`, `id`, `store` |
| `read_property` | 读取属性 | `source`, `property`, `store` |
| `count` | 计数 | `source`, `store` |
| `compare` | 比较运算 | `operator` (==/!=/>/>=/</<=/truthy/falsy), `left`, `right`, `store` |
| `and`/`or`/`not` | 布尔逻辑 | `sources[]` / `source`, `store` |
| `set` | 设值 | `value`, `store` |
| `assert` | 标记达成 | `source`, `title` |
| `sub_goal` | 子目标追踪 | `source`, `name` |
| `wait_frames` | 防抖等待 | `source`, `frames` (默认5) |
| `voltage` | 节点电压 | `nodeKey` / `componentId`, `store` |
| `voltage_diff` | 两端压差 | `source` (元件), `store` |
| `exists` | 存在检查 | `type`, `id`, `store` |

### store 引用语法

- `$storeName` → 引用 store 中的值
- `$storeName.property` → 引用 store 中对象的属性
- 字面量 → 原样使用

启动新会话后按此顺序处理：

## 五、扩展架构 (远期规划)

### 教师端编辑器 `ExperimentDesigner.vue`

```
ExperimentDesigner
  ├─ BasicInfoForm         实验标题、难度、时长
  ├─ ComponentSelector     勾选可用元件
  ├─ CircuitPreview        Canvas 预览预设电路 (复用引擎绘制)

  └─ PublishButton         保存 config 到数据库
```

### 数据库 `experiment_configs` 表

```sql
CREATE TABLE experiment_configs (
  id INT PRIMARY KEY AUTO_INCREMENT,
  exp_id INT NOT NULL UNIQUE,
  config JSON NOT NULL COMMENT '实验配置',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (exp_id) REFERENCES experiments(exp_id) ON DELETE CASCADE
);
```
