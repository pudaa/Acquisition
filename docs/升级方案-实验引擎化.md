# 虚拟实验引擎化改造方案

## 一、现状与问题

### 当前架构

```
teacher 上传完整 HTML + 资源文件
       ↓
存储到 frontend/public/experiments/{id}/index.html
       ↓
学生通过 iframe 加载对应 HTML
```

### 核心问题

1. **12 套重复 HTML**：每个实验的 `index.html` 都是同一套电路模拟器副本，仅在工具栏按钮配置和目标检测上做极少量微调
2. **教师上传门槛高**：必须准备完整 HTML 文件，无法在线可视化配置
3. **实验文件 & 构建耦合**：`public/` 是构建目录，实验文件存在其中不符合工程规范
4. **进度与文件强绑定**：若实验文件被清除或路径变更，学生学习记录丢失（虽然表中仍有数据）
5. **扩展性差**：新增实验类型需手写 HTML + JS，无法灵活组合

---

## 二、目标架构："引擎 + 配置" 模式

将实验系统重构为两层：**渲染引擎（不变）** + **实验配置（数据驱动）**。

```
ExperimentEngine (Vue 组件，替代 iframe)
  ├─ ComponentRegistry    元件注册表（已有）
  ├─ CircuitSolver        电路求解器（已有）
  ├─ GoalSystem           目标检测系统（已有骨架，需配置化）
  ├─ ToolbarRenderer      工具栏渲染器（新增）
  └─ ExperimentConfig     实验配置驱动（新增，核心）
```

### 2.1 实验配置数据结构

实验不再是一个 HTML 文件，而是数据库中的一条 JSON 配置记录：

```json
{
  "expId": 1,
  "title": "与门搭建实验",
  "difficulty": "basic",
  "availableComponents": ["wire", "battery", "ground", "switch", "resistor", "bulb", "and-gate", "or-gate"],
  "presetCircuit": {
    "components": [
      { "type": "battery", "x": 100, "y": 100 },
      { "type": "bulb", "x": 300, "y": 100 }
    ],
    "wires": []
  },
  "goals": [
    { "id": "GOAL_BULB_LIT", "type": "behavioral", "description": "成功让灯泡发光", "weight": 2 },
    { "id": "GOAL_AND_GATE_1", "type": "structural", "description": "使用至少 1 个与门", "weight": 1 }
  ],
  "passingScore": 60,
  "availableElements": [1, 2, 3, 4]
}
```

### 2.2 数据库表变更

**新增 `experiment_configs` 表**，替代文件存储：

```sql
CREATE TABLE experiment_configs (
  id INT PRIMARY KEY AUTO_INCREMENT,
  exp_id INT NOT NULL UNIQUE,
  config JSON NOT NULL COMMENT '实验配置（可用元件、预设电路、目标）',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (exp_id) REFERENCES experiments(exp_id) ON DELETE CASCADE
);
```

`experiments` 表中原有的 `steps`、`element` 字段逐渐迁移到 `config` 中。

### 2.3 前端改造点

#### 2.3.1 引擎组件 `ExperimentEngine.vue`

替代当前 `ExperimentLearningView.vue` 中的 iframe 方案，直接在同域下运行电路模拟器：

```
ExperimentLearningView
  └─ ExperimentEngine (新组件)
       ├─ Toolbar           ← 根据 config.availableComponents 动态渲染
       ├─ CircuitCanvas     ← 已有 Canvas 逻辑
       ├─ GoalPanel         ← 根据 config.goals 动态渲染
       └─ GoalDetector      ← 根据 config.goals 条件动态检测
```

#### 2.3.2 通讯改造

当前通过 `postMessage` 在 iframe 与父页面间通讯。
改造后引擎与学习视图在同一个 Vue 组件内，直接通过函数调用/Props 通信，消除 `postMessage` 依赖：

```
现状：  ExperimentLearningView ← postMessage → iframe (experiments/{id}/index.html)
改造后：ExperimentLearningView ← Props/Events → ExperimentEngine (Vue 组件)
```

#### 2.3.3 工具栏动态化

当前每个实验 HTML 的工具栏按钮是手写的：

```html
<button data-type="wire">导线</button>
<button data-type="battery">电源</button>
```

改造后从配置动态生成：

```vue
<button v-for="comp in config.availableComponents" :data-type="comp">
  {{ componentLabels[comp] }}
</button>
```

### 2.4 教师端可视化编辑器

新增 `ExperimentDesigner.vue`：

```vue
ExperimentDesigner
  ├─ BasicInfoForm         实验标题、难度、时长
  ├─ ComponentSelector     勾选可用元件
  ├─ CircuitPreview        Canvas 预览预设电路（复用引擎绘制逻辑）
  ├─ GoalEditor            可视化配置检测目标
  │    ├─ 添加结构目标（如"至少 4 个电阻"）
  │    └─ 添加行为目标（如"灯泡发光"）
  └─ PublishButton         保存 config 到数据库
```

## 三、分阶段实施计划

### 第一阶段：配置化基础（2-3 天）

1. 创建 `experiment_configs` 表
2. 从现有实验提取配置参数，为 6 个标准实验生成 config JSON
3. 新增 `GET /api/experiments/:id/config` 接口
4. 重构 `ExperimentEngine.vue`：动态加载实验配置、动态渲染工具栏

### 第二阶段：移除 iframe 依赖（2-3 天）

1. 将 `frontend/public/js/` 下的核心引擎 JS 模块化，迁入 `src/engine/`
2. 通过 Vite 打包纳入构建，消除 `public/` 文件依赖
3. `ExperimentEngine.vue` 直接 import 电路模拟逻辑，不再通过 iframe 加载
4. 替换 `postMessage` 通信为组件 Props/Events

### 第三阶段：可视化编辑器（3-4 天）

1. 开发 `ExperimentDesigner.vue` 教师端编辑器
2. 实现拖拽式预设电路配置
3. 实现目标可视化编辑
4. 接入保存发布流程

---

## 四、风险与注意事项

- **电路模拟 JS 独立代码**：`frontend/public/js/` 下是原生 ES Module，迁移到 Vite 构建时需测试兼容性
- **现有实验兼容**：第一阶段要保证新旧实验同时可用
- **性能考量**：引擎作为 Vue 组件直接渲染 Canvas，避免 iframe 额外开销
