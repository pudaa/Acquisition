# 虚拟电路引擎 — 实现评估

对照完整规范的架构要求，评估当前引擎的实现程度。

## 一、电路模型层

| 要求 | 当前状态 | 评估 |
|---|---|---|
| **元件库** | 电阻、电容、电感、灯泡、开关、电池、接地、二极管、NPN/PNP 三极管、5种逻辑门 | ✅ 已覆盖（电感求解器已支持但 UI 工具栏未添加） |
| **引脚/端口系统** | `circuit-component.js` 定义了 `COMPONENT_PINS` 和 `getActualPins` | ✅ 支持旋转矩阵 |
| **电路图/网表** | `getAllNodesAndEdges` 使用并查集 + 邻接表 | ✅ |
| **元件 ID 注册** | `component-registry.js` 自动分配 R1/B1/L1/… | ✅ 2026-06-27 新增 |
| **注册式绘制** | `renderer-registry.js`, 14 种内置, `registerRenderer()` 扩展 | ✅ 2026-06-27 新增 |

## 二、仿真引擎层

| 要求 | 当前状态 | 评估 |
|---|---|---|
| **求解器 - 直流分析** | `solveCircuit()` 使用 MNA + 高斯消元 (列主元) | ✅ |
| **求解器 - 瞬态分析** | 电容梯形积分 + 电感向后欧拉 (均 A-稳定) | ✅ 2026-06-27 修复 |
| **牛顿-拉夫逊迭代** | 最多 20 次迭代, 容差 1e-6 | ✅ 2026-06-27 新增 |
| **三极管模型** | Ebers-Moll: Ic=β·Ib, 双二极管 + 受控源, NR 迭代 | ✅ 2026-06-27 升级 |
| **二极管模型** | 指数模型: Id=Is·(exp(Vd/nVt)-1), NR 迭代 | ✅ 2026-06-27 升级 |
| **数字仿真** | 逻辑门用电压阈值 (2.49V) | ⚠️ 无事件队列, 每帧全量求解 |
| **混合信号** | 同一 MNA 矩阵混合处理 | ✅ |
| **时间管理系统** | `TimeManager` 固定步长 1ms, 防螺旋, rAF 驱动 | ✅ 2026-06-27 新增 |
| **仿真编排器** | `SimulationEngine` 统筹时间/求解/目标/渲染 | ✅ 2026-06-27 新增 |

## 四、待解决问题

### 紧急

1. **`seed-experiment-configs.js` 配置格式过时**
   - `presetCircuitFile` 引用已删除的 `public/circuit/*.json` → 改为内联 `presetCircuit.components`
   - `goals` 使用旧 `type` 格式 → 迁移到 `type:"workflow"`
   - 预设元件需要 `id` 字段才可被工作流引用

2. **`ExperimentLearningView.vue` 使用 Options API**
   - `this.$route`, `data()`, `methods` → `<script setup>`, `useRoute()`, `ref()`

3. **`ExperimentEngine.vue` 旧代码残留**
   - 脚本末尾可能仍有重复的 `onMouseMove` 等函数声明

### 重要

4. **Canvas 坐标精度**
   - `onCanvasClick` 中 `Math.round(currentMouseX / gs)` 未减去 `ctx.translate(10,10)` → 元件偏移约 10px

5. **逻辑门无事件队列**
   - 当前每帧全量求解, 数字切换时序不精确

6. **示波器空通道时无反馈**
   - 无节点时显示空白, 应有 "无信号" 提示

### 低优先级

7. 教师端 `ExperimentDesigner.vue` 可视化编辑器
8. 运算放大器模型
9. 交流小信号分析
