# **此文件用于重构虚拟实验代码，将其模块化代码**

## 代码中包含以下函数：

- initEventListeners
  - nitEventListeners 用于初始化页面中的各种事件监听器，具体功能如下：
    1. 工具栏按钮点击：为每个 .component-btn 添加点击事件，实现单选效果，并设置 selectedComponentType；
    2. 删除按钮切换：点击 #delete-btn 切换删除模式，并高亮显示；
    3. 画布事件绑定：绑定鼠标移动、点击、右键、离开等事件处理函数；
    4. 页面加载后绘制：页面加载完成后绘制网格并启动帧循环。
  
- handleMouseMove

  -  [handleMouseMove](javascript:void(0)) 用于处理鼠标在画布上的移动事件，主要功能如下：
    1. 获取鼠标在画布中的坐标；
    2. 检测鼠标是否在画布范围内；
    3. 若有选中组件且鼠标在画布内，则根据网格对齐计算临时组件位置，并更新临时组件对象；
    4. 否则清空临时组件。

- getActualPins

  -  `getActualPins` 用于计算元件（如电路元件）在画布上旋转后的真实引脚坐标位置，具体逻辑如下：
    1. 如果元件是导线（wire），则直接返回两个端点并吸附到网格；
    2. 否则根据元件类型查找预定义引脚位置；
    3. 根据元件的旋转角度进行坐标变换；
    4. 所有坐标经过网格吸附处理，防止小数误差。

- handleCanvasClick

  - 实现了点击画布放置电子元件的功能，具体逻辑如下：
    1. **删除模式**：若启用删除模式，则移除最近的元件。
    2. **导线连接**：选择导线时，记录起点和终点引脚，创建导线组件。
    3. **三极管处理**：输入放大倍数 β 后创建三极管元件。
    4. **开关处理**：创建初始状态为闭合的开关。
    5. **其他元件（电阻、电容等）**：根据类型弹窗输入参数，并创建对应元件。

- handleMouseLeave

  - 鼠标离开画布后，删除跟随鼠标的暂存元件并刷新

- drawComponent

  - `drawComponent` 用于在 Canvas 上根据元件类型绘制不同的电子元件图形，支持电阻、电池、灯泡、电容、二极管、三极管等多种元件。功能如下：
    1. 设置绘制上下文并进行位移和旋转；
    2. 根据 `component.type` 使用 `switch` 绘制不同元件；
    3. 支持元件状态（如开关、发光）动态显示；
    4. 绘制引脚小圆点；
    5. 最后恢复上下文状态。

- saveHistory

  - `saveHistory` 用于**保存当前组件状态到历史记录栈中**，以便支持撤销等操作。

    解释如下：

    - `historyStack.push(...)`：将当前状态压入历史栈；
    - `{ components: [...components] }`：复制当前 [components](javascript:void(0)) 数组内容作为一个新对象保存。

- findNearestPin

  - `findNearestPin` 的功能是：**在画布上查找距离鼠标位置最近的“引脚”（pin）**，并返回该引脚及其所属组件的信息。

    具体逻辑如下：

    1. 获取鼠标在 canvas 上的坐标；
    2. 遍历所有组件及其引脚，计算每个引脚到鼠标的距离；
    3. 若引脚距离小于 15 像素且为当前最小，则更新为最近引脚；
    4. 返回最近的引脚对象（含坐标、组件和索引）。

- findNearestComponent

  - `findNearestComponent` 的功能是：**在画布上查找距离鼠标位置最近的元件（component）**。

    具体逻辑如下：

    1. 获取鼠标在 canvas 上的实际坐标；
    2. 遍历所有元件及其引脚（pin），计算鼠标与每个引脚之间的距离；
    3. 如果引脚距离鼠标小于 20 像素，且是当前最小距离，则更新最近的元件；
    4. 返回距离最近的元件对象。

- handleRightClick

  - 实现了画布上的右键点击功能：
    1. 如果有临时元件（`tempComponent`），则每次右键点击将其旋转90度；
    2. 如果没有临时元件，则查找最近的引脚，若该引脚属于开关元件，则切换其开/关状态。
       最终都会调用 `draw()` 更新画面。

- drawGrid

  - 用于在 Canvas 画布上绘制网格背景。功能如下：
    1. 设置线条颜色为淡灰色（`#f5f5f5`）；
    2. 设置线条宽度为 1 像素；
    3. 使用两个循环分别绘制垂直和水平的网格线，间距为 `GRID_SIZE`。

- drawWire

  - 用于在 Canvas 上绘制从起点 `start` 到终点 `end` 的折线导线，折线遵循网格对齐规则：
    - 计算起点到终点的横向（dx）和纵向（dy）距离
    - 若横向距离更大，则先水平再垂直绘制，折点对齐网格
    - 否则先垂直再水平绘制，折点同样对齐网格
    - 最后绘制至终点并描边显示导线

- simulateCircuit

  - 用于模拟并显示电路状态，包括是否通电、灯泡是否点亮、振荡器是否工作。具体逻辑如下：
    1. 获取节点电压和电路元件信息。
    2. 查找电池并检测其电压是否正常（>4.5V）。
    3. 检查灯泡是否点亮（复用已有逻辑）。
    4. 检测是否存在正常工作的多谐振荡器。
    5. 将结果输出到页面的 `output` 元素中。

- draw

  - 是电路模拟器的核心绘制逻辑，主要完成以下功能：
    1. 清除画布并重绘网格；
    2. 绘制所有导线（wire）；
    3. 获取电路节点并求解节点电压；
    4. 更新电容器状态；
    5. 遍历所有元件，计算其电压、电流，并根据类型绘制；
    6. 显示电流（I）和电压（V）信息；
    7. 绘制临时元件与连线预览；
    8. 模拟电路行为；
    9. 记录灯泡电压差历史用于后续分析；
    10. 检查目标条件是否达成。

- frameLoop

  - 用于动态控制定时重绘，实现类似动画循环的功能。具体逻辑如下：
    1. **清除之前的动画帧请求**（`cancelAnimationFrame`）。
    2. 启动定时器，每隔frameInterval毫秒执行一次：
       - 记录绘制耗时；
       - 调用 `draw()` 进行绘制；
       - 根据绘制时间动态调整下一次间隔时间（最小16ms，最大100ms），以避免帧积压或过度渲染。

- getAllNodesAndEdges

  - 用于自动识别电路图中所有电气连接的节点和支路，支持并联和混联结构。其主要功能如下：
    1. **收集引脚坐标并去重**：遍历元件引脚，吸附到网格后生成唯一键（`x,y`），构建唯一节点列表。
    2. **使用并查集合并导线连接的点**：通过导线连接的点视为同一节点，用并查集实现连通分量合并。
    3. **重新编号物理节点**：为每个连通分量分配唯一编号，建立映射关系。
    4. **收集支路信息（边）**：记录每个元件连接的两个物理节点编号，形成边集合。
    5. **返回结果**：包括节点列表、边列表及辅助映射表。

- updateConductanceMatrix

  - 用于**更新导纳（电导）矩阵**，减少重复代码。功能如下：
    - 给节点 `idx1` 和 `idx2` 自导（对角线元素）增加电导 `g`
    - 给互导（非对角线元素）减去电导 `g`，体现支路连接关系
    - 常用于电路仿真中构建节点导纳矩阵

- solveNodeVoltages

  - 实现**电路中节点电压的自动求解**，主要功能如下：
    1. **收集电路中的节点和支路信息**；
    2. **识别电源（电池）和接地节点**；
    3. **构建电导矩阵 G 和电流向量 I**；
    4. **处理各种元件（电阻、电容、二极管、三极管等）对电路的影响**；
    5. **使用高斯消元法求解线性方程 GV = I，得到各节点电压**；
    6. **保存结果用于后续动态元件（如三极管）的状态判断**。

- isConnected

  - 用于判断两个点（`pin1` 和 `pin2`）是否在指定的网格范围内相连。

    解释如下：

    - 函数通过比较两个点的 `x` 和 `y` 坐标差值是否小于等于 `GRID_SIZE/2`，来判断它们是否处于同一网格内或相邻网格内。
    - 只有当横向和纵向距离都满足条件时，才返回 `true`，表示这两个点“连接”。

- updateCapacitors

  - 用于模拟电路中电容（包括电解电容）的充放电动态过程，主要功能如下：

    1. **获取电容两端电压**：通过节点映射找到电容两个引脚对应的电压。

    2. **处理电解电容反接保护**：若正负极反接超过0.5V，模拟损坏并置电压为0。

    3. 计算等效电阻（R）

       ：

       - 包括固定ESR（等效串联电阻）；
       - 根据拓扑结构累加串联或并联电阻；
       - 考虑三极管接入时的动态电阻。

    4. **计算时间差（dt）**：基于上次更新时间确定实际经过的时间。

    5. **RC充放电模型**：使用指数衰减公式模拟电容电压随时间变化。

    ```javascript
    jsconst tau = equivalentR * C;
    const alpha = Math.exp(-realDT / tau);
    comp.currentVoltage = Vab * (1 - alpha) + comp.currentVoltage * alpha;
    ```

    这是典型的RC一阶充放电电压更新公式。

- checkGoals

  - 用于检测电路中是否达成预设的几个目标状态

- onComponentsChanged

  - 用于根据电路组件变化更新目标状态：
    1. 统计当前 NPN 或 PNP 类型的晶体管数量，若少于 2 个，则关闭 `goalStatus.TRANSISTOR_2` 标志；
    2. 检查是否存在灯泡组件，若不存在，则关闭 `goalStatus.BULB_LIT` 标志。

- detectMultivibrator

  - 用于检测电路是否构成**多谐振荡器（Multivibrator）**，分为两部分判断：

    1. **结构法判断**：检查电路中是否至少包含一个晶体管、一个电容和一个灯泡；
    2. **行为法判断**：通过灯泡两端电压变化的平均差值是否超过0.05V，判断是否存在振荡行为。

    最终返回是否满足结构要求（`structureOk`）。


## 函数共区分为一下模块：

- 电路节点与元件建模相关的工具函数
- 元件绘制相关函数
- 历史记录/撤销功能
- 目标检测与成就系统
- 通用的事件绑定与处理
